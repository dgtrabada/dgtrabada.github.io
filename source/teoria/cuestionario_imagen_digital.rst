******************************
Cuestionario imagen digital
******************************

.. cuestionario::

   1. Codificación de imagen:
      - Tenemos una pantalla con 2x3 píxeles y cada píxel tiene 256 colores, es decir 8 bits, ¿cuántos Bytes de información caben en esta pantalla?
        imagen: imagenes/pantalla_2x3.png
        [6] B
      - ¿Cuántos colores se pueden representar con una profundidad de 24 bits (color real)?
        = 16777216 | 16.777.216 | 2^24
      - ¿Cuántos Bytes ocupa una imagen Full HD (1.920 x 1.080) en color real (24 bits) sin comprimir?
        [6220800 | 6.220.800] B

   2. Resolución y formatos:
      - Si una imagen tiene una resolución de 200 ppp, ¿cuántos píxeles hay en cada pulgada cuadrada?
        [40000 | 40.000] píxeles
      - ¿Cuál de estos formatos es vectorial?
        ( ) JPG
        ( ) PNG
        (x) SVG
        ( ) BMP
      - ¿Cuál de estos formatos comprime las imágenes con pérdida de calidad?
        (x) JPG
        ( ) PNG
        ( ) GIF
        ( ) TIFF
